# Specs (planes de prueba)

Directorio donde el agente **playwright-test-planner** guarda los planes de prueba en Markdown
que luego usa **playwright-test-generator** para crear los specs en `tests/`.

Ejemplo de uso con Claude Code:

```
Usa el agente playwright-test-planner para crear un plan de pruebas del flujo
de carrito de https://www.saucedemo.com y guárdalo en specs/carrito.md
```
